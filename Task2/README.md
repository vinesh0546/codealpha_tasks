# CodeAlpha Phishing Awareness Training

## Task
CodeAlpha Cyber Security Internship — Task 2: Phishing Awareness Training.

## Project Overview
This project is an interactive web-based phishing awareness training module. It explains phishing attacks, recognition of phishing emails and fake websites, social engineering tactics, prevention practices, real-world scenarios, and an interactive quiz.

## Features
- Phishing definition and objectives
- Common phishing types
- Phishing email warning signs
- Fake website identification tips
- Social engineering tactics
- Best practices for staying safe
- Real-world phishing scenarios
- Guidance after clicking a suspicious link
- 10-question interactive quiz with score

## Technologies
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the project.
2. Open `index.html` in a modern web browser.
3. Read the training sections.
4. Complete the interactive quiz.
5. Click **Submit Quiz** to view the score.

No external libraries or server are required.
